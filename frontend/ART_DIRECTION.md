# Art Direction

A sober, modern cybersecurity intelligence interface with restrained futuristic illumination and subtle environmental interactivity.

The visual language uses deep mineral blue-green surfaces, crisp warm-white typography, thin technical rules, one controlled cyan accent, and amber/red only for risk. Cards feel like precision instruments rather than generic admin panels. A low-contrast environmental grid and cursor halo create depth without competing with evidence. Light mode uses cool paper-like surfaces and desaturated teal shadows instead of a simple color inversion.

Motion communicates state: upload focus, processing, navigation, and threat severity. It is brief, optional, and disabled under `prefers-reduced-motion`.
